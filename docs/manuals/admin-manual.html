管理者マニュアル

管理画面(/admin)の各ページで「何ができるか」「どう使うか」を、画面の並び順にそって説明します。 迷ったときは左のメニューからページ名をクリックしてください。

アカウントと権限

管理画面へのログインはすべて同じ画面(/login)から行います。ログイン後に表示される内容は、そのアカウントに割り当てられた「役割」によって自動的に変わります。役割は4種類あります。

管理者(admin)すべての画面を利用でき、登録・変更・削除などの操作もすべて行えます。他の管理者アカウントの追加・停止もこの役割だけが行えます。
閲覧管理者(admin_viewer)管理者と同じ画面がすべて見えますが、登録・変更・削除といった操作はサーバー側で拒否されます。画面上部に閲覧専用であることを示す帯が表示されます。会計監査や研修などで「見せるだけ」にしたい場合に使います。
スタッフ(staff)日々の運用に必要な画面だけに限定されています。具体的には ダッシュボード・商品一覧・CSV一括登録・注文管理・外部注文の登録・発行状況の管理・受取用ウォレット未登録者・お知らせ です。それ以外のメニュー項目(紹介・代理店まわり、法務、設定、操作履歴、管理者アカウント、外部連携・監視のすべて)は画面に表示されず、URLを直接入力してもダッシュボードへ戻されます。
代理店(agency)専用のログイン画面(/agency)からログインする別ポータルです。本マニュアルの対象外です。
i

本マニュアル内の役割表示について各ページの見出し横に、そのページを利用できる役割を色分けチップで示しています。「スタッフも利用可」の表示がないページは、管理者・閲覧管理者専用です。

!

新しい管理者アカウントの作り方管理者がその場で仮パスワードを設定してあげることはできません。管理者アカウントページから招待すると、本人宛にパスワード設定用のメールが送られ、本人がリンクから自分でパスワードを設定する流れになります。

概要

最初に開かれる画面

ダッシュボード

スタッフも利用可

/admin

ログイン後に最初に表示される画面です。売上のサマリー、直近の注文件数、発行待ちのデジタル会員証件数などがグラフとカードで一覧表示されます。この画面自体には操作ボタンはなく、状況を一目で把握するための画面です。気になる数字があれば、対応する各ページ(注文管理・発行状況の管理など)に移動して詳細を確認してください。

商品・注文

商品一覧

スタッフも利用可

/admin/products

登録済みの商品を一覧で確認できます。ここから新規登録・編集ページへ進みます。

商品の新規登録

スタッフも利用可

/admin/products/new

入力する項目

商品名・説明文購入者に表示される名前と紹介文です。
URL用の識別子(スラッグ)商品ページのURLに使う英数字です。登録後は変更できません。公開前に確認してください。
カテゴリー・種別・販売方式商品の分類と、通常販売か予約販売かなどの販売方式を選びます。
価格税込・税抜どちらで入力するかを切り替えられます。表示時は必ず「税込」表記になります。
バリエーション(種類・在庫)色・ランクなどの種類ごとに、在庫数を必ず設定します。在庫が0になると購入できなくなります。
画像商品ページに表示される画像をアップロードします。

商品の編集

スタッフも利用可

/admin/products/:id/edit

公開状態は「下書き・公開中・アーカイブ済み」の3段階です。バリエーションの在庫数などは入力欄からフォーカスを外す(クリックして別の場所を押す)と自動的に保存されます。保存ボタンを押し忘れても反映されるため、入力後は数秒待ってから画面を離れてください。

i

「連携ルール(千ノ国連携)」欄について編集画面の下部に外部システム連携用の設定欄がありますが、画面上に「現在は無効」である旨が明記されている通り、現時点では動作していません。将来の連携機能のための準備欄です。触らなくて構いません。

CSV一括登録

スタッフも利用可

/admin/import-products

多数の商品をまとめて登録・更新したいときに使います。

  1. 「サンプルCSVをダウンロード」から雛形を取得します(必須の列がすべて入っています)。
  2. 雛形に沿って表計算ソフトで内容を入力し、CSV形式で保存します。
  3. ファイルを選択すると、登録前に内容の「プレビュー」が表示されます。
  4. プレビューの内容に間違いがないことを確認してから「実行」します。プレビューの段階ではまだ何も登録されません。

注文管理

スタッフも利用可

/admin/orders

すべての注文を確認できます。「CSVエクスポート」で一覧を書き出せます。

銀行振込の入金確認

銀行振込を選んだ注文には「入金確認」ボタンが表示されます。実際に入金を確認できてから押してください。このボタンを押した時点で決済完了として扱われ、デジタル会員証の発行手続きが始まります。

!

クレジットカード決済は自動で確定しますクレジットカード決済の完了は、購入者が「完了しました」という画面を見た時点ではなく、Stripe(決済代行会社)からの通知を受け取った時点で確定します。この画面上の操作で決済状態を手動で「完了」に変えることはできません(銀行振込を除く)。

注文ステータスの変更

ステータスの選択肢は現在の状態から遷移できる範囲だけが表示されます(すでに完了した注文を「未決済」に戻す、といった操作はできません)。「説明責任者」欄は自由記入で、対応した担当者名などを控えるためのメモ欄です。

NFT(デジタル会員証)

画面上の表記は「NFT」のままの箇所があります

外部注文の登録

スタッフも利用可

/admin/external-orders

イベント会場での手売りなど、このカートを通さずに代金を受け取った購入者について、デジタル会員証の発行対象として登録するための画面です。1件ずつの手入力フォームと、CSVによるまとめ登録の両方に対応しています。

i

登録後も購入者本人の操作が必要ですここで登録しても、受取用ウォレットの接続と本人確認(署名)は購入者自身に行ってもらう必要があります。登録が済んだ購入者は受取用ウォレット未登録者の一覧に現れます。

発行状況の管理

スタッフも利用可

/admin/nft-issues

デジタル会員証1枚ごとの発行状況を確認・操作します。ステータスで絞り込みできます。

ウォレット待ち→ 発行準備完了→ 発行処理中→ 発行済み

※処理中に失敗すると「発行準備完了」に自動で戻り再試行されます。既定の再試行回数を超えると「発行失敗」になります。返金・キャンセル時は「発行取消」になります。

「発行失敗」または「発行準備完了」の行には再試行ボタンが表示されます。外部の発行サービス側で先に手動発行した場合などは、トークンIDと取引ハッシュ(txハッシュ)を手入力して「発行済み」に直接変更することもできます。

受取用ウォレット未登録者

スタッフも利用可

/admin/wallet-missing

デジタル会員証の対象商品を購入したものの、まだ受取用ウォレット(Web3用語でいうWallet)を登録していない購入者の一覧です。一覧から登録案内メールの送信・再送信ができます。すでに送信済みの記録を消して送信履歴をリセットする操作も可能です。

i

ここから直接ウォレットを登録することはできません受取用ウォレットの登録には、本人による署名(本人確認)が必須です。誤入力や成りすましによる誤発行を防ぐため、管理者が代わりにアドレスを入力する機能は用意していません。必ず購入者本人にメール等の案内から登録してもらってください。

紹介・代理店

スタッフのメニューには表示されません

紹介リンク発行

管理者のみ利用可

/admin/referral-links

インフルエンサーが使う紹介リンクを発行します。この画面はスマートフォンでの操作を前提にレイアウトされています。

  1. 代理店を選びます。まだ登録がない場合はその場で新規作成できます。
  2. インフルエンサーを選びます。こちらもその場で新規作成できます。
  3. 必要であれば紹介報酬率を個別に上書きします(未入力ならインフルエンサー・代理店の既定値が使われます)。
  4. 「発行」を押すとリンクが作成され、URLをコピーできます。
!

発行後の編集・削除はできませんリンクの紹介コードや条件を後から書き換えることはできません。条件を変えたい場合は、既存のリンクを「無効化」してから新しく発行し直してください。紹介コードは自動採番(SGI+連番)で、任意の文字列を指定することもできません。

クーポン

管理者のみ利用可 閲覧管理者は閲覧のみ

/admin/coupons

定額または割合(%)割引のクーポンを作成します。割引上限額・最低購入金額・有効期限・利用回数上限を設定できます。

!

クーポンは店舗全体に適用されます特定の商品だけ・特定の代理店経由の注文だけ・特定の顧客だけ、といった対象の絞り込みは現状できません。発行するクーポンは常に全商品・全購入者が対象になる前提で設計してください。

紹介実績・報酬

管理者のみ利用可

/admin/referrals

紹介経由の売上・報酬額を集計表で確認します。CSVエクスポートに対応し、支払い待ちの報酬を選んでまとめて「承認済み」にするチェックボックスもあります。行ごとのステータスは現在の状態から遷移できる範囲だけが選択できます。

代理店

管理者のみ利用可

/admin/agencies

代理店の一覧を確認します。外部の代理店管理システムと同期する読み取り専用ボタンのみで、この画面から直接新規作成・編集することはできません(代理店の新規作成は紹介リンク発行画面のインライン作成から行います)。

その他

お知らせ

スタッフも利用可

/admin/notices

購入者向けのお知らせを下書き作成し、公開・非公開を切り替えます。不要になったものは削除できます。

法務ページ

管理者のみ利用可

/admin/legal

4つのタブ(特定商取引法表記・利用規約・プライバシーポリシー・その他)を編集します。「特定商取引法」タブだけは項目ごとの入力フォームです。残り3つのタブは簡易的な記法を使ったフリーテキストで、以下のルールで書きます。

## 見出し行頭に半角の ## と半角スペースを付けると見出しになります。
!注意文行頭に半角の ! を付けると、目立つ注意書きボックスになります。
項目名|内容半角の |(縦棒)で区切ると、表の1行になります。連続する行は自動的にまとめて1つの表になります。
それ以外の行通常の段落として表示されます。
!

記法を1文字でも間違えると見た目が崩れます特に ## の後ろの半角スペースや、| の全角・半角の違いに注意してください。保存後は必ずプレビュー(公開ページ)で見た目を確認してください。

管理者アカウント

管理者のみ利用可

/admin/admin-users

管理者・閲覧管理者・スタッフのアカウントを作成・編集・停止します。新規作成すると本人宛に仮パスワード設定用のメールが自動送信されます。管理者が代理でパスワードを設定して伝える方法は用意されていません(セキュリティ上の理由により、仮パスワードを平文でメール送信することもありません)。

操作履歴

管理者のみ利用可

/admin/audit-logs

管理画面・代理店ポータルで行われたすべての変更操作(登録・編集・削除など)の記録です。閲覧専用で、誰が・いつ・何を行ったかを追跡する用途です。

設定

管理者のみ利用可 閲覧管理者は閲覧のみ 初期設定・障害対応向け

/admin/settings

決済(Stripe)・メール送信(Resend)・代理店連携・デジタル会員証の自動発行サービスなど、外部サービスとの接続情報(APIキー)をまとめて管理する画面です。項目ごとに「接続テスト」ボタンがあります。日常的に使う画面ではなく、初期設定時やトラブル発生時に確認・変更する画面と考えてください。

i

空欄のまま保存すると、既存の値は消えませんキーを入力し直さずに保存しても、既に登録済みの値は上書きされず保持されます。銀行振込の受付可否と振込先案内文もこの画面の別セクションで設定しますが、入金の確認・確定は注文管理画面で行います(この画面では行いません)。

外部連携・監視

スタッフのメニューには表示されません
!

このグループの中でも「Wallet Claims」「Collectible Deliveries」の2つだけは今すぐ使う画面です残りの画面(下記「連携監視画面(その他)」)は千ノ国という外部システムとの連携機能に関するもので、現時点ではその連携自体が無効化されているため使用しません。しかし同じメニューグループに並んでいるだけで、Wallet ClaimsとCollectible Deliveriesはこの連携の有効・無効に関係なく現在も稼働している、購入者サポート用の画面です。

Wallet Claims

管理者のみ利用可

/admin/wallet-claims, /admin/wallet-claims/:id

注文単位で、受取用ウォレットの登録・受け取りURLの状態を確認する画面です。詳細画面では、注文に含まれるデジタル会員証1枚ごとの送付状況と操作履歴が確認できます。「受け取りが届いていない」という問い合わせがあったとき、まずこの画面で状況を確認してください。

状態が「保留中・期限切れ・エラー」のときだけ「受け取り用URLを再発行する」ボタンが使えます。

i

できないこと元のトークン文字列の確認、権利情報(entitlement)の付け替え、「受け取り完了」になった記録を手動で取り消すことは、いずれもできません。

Collectible Deliveries

管理者のみ利用可

/admin/collectible-deliveries, /admin/collectible-deliveries/:id

上の「Wallet Claims」が注文単位の一覧なのに対し、こちらはデジタル会員証1枚ずつの送付状況を確認する画面です。「注文全体は受け取り済みなのに、カードが1枚だけ届いていない」といった、より細かい単位のトラブル対応に使います。

状態が「送付失敗・送付不能」のときだけ「今すぐ再送信」ボタンが使えます。こちらも「受け取り済み」の記録を手動で取り消す機能はありません。

連携監視画面(その他)

管理者のみ利用可 現在は未使用

以下はすべて、千ノ国という外部システムとの将来的な連携機能のための画面です。連携機能自体が現時点で無効化されているため、通常の運用では使いません。

Integration Preflight連携を有効化する前の事前チェック結果を表示します。
Integration Outbox外部システムへ送信予定・送信済みのイベントの一覧です。
Order Linking Jobs外部システムの注文とこのカートの注文を紐付ける処理の状況です。
External Identity Conflicts外部システムのユーザーIDが重複・矛盾した場合の一覧です。
Wallet Transactionsウォレット関連の取引記録の一覧です。
Integration Rules Overview商品ごとの外部連携ルール設定の一覧です。
Notification Outbox購入者宛のメール等の通知送信キューの一覧です。
